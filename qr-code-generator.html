Where Ecommerce Sellers Actually Use QR Codes

A QR code is only useful if it drives a specific action, so it's worth matching the content type to the placement. A packaging insert pointing to a review page turns a delivery into a review request. A print ad or flyer linking straight to a product page skips the "search for the brand" step entirely. An in-store shelf display can link to a product demo video or size guide a shopper would otherwise have to ask staff about. And a QR code on a receipt is a low-friction way to invite a customer back for a reorder or a loyalty signup, right when the purchase is still fresh in mind.

Static vs. Dynamic QR Codes

Every code this tool generates is a static QR code: the destination is encoded directly into the pattern itself, so it's free, works forever, and never depends on a third-party service staying online. The tradeoff is that the destination can't be changed later without reprinting the code. A dynamic QR code instead points to a short redirect URL hosted by a paid service, so you can repoint it to a new destination after it's already printed. You only need dynamic if you expect to change the link later, for example on packaging that's expensive to reprint, or if you want scan analytics. For most one-off uses, like a flyer or a single product's packaging, static is simpler and genuinely free.

Minimum Print Size for Reliable Scanning

As a baseline, print QR codes at at least 2x2cm (0.8x0.8in) for scans from roughly 30cm away, which covers most packaging and shelf-tag use cases. Scale up proportionally for greater distances: a poster meant to be scanned from a few meters away needs a code several times larger. Denser codes, like ones using a long URL, a WiFi payload, or a high error correction level, need more print resolution to stay scannable at small sizes, which is why this tool offers export sizes up to 2048px for large-format print.

Frequently Asked Questions

What size should a QR code be for packaging?

A good rule of thumb is at least 2x2cm (0.8x0.8in) for scans from roughly 30cm away, scaling up proportionally for greater scan distances, such as posters or banners. Always test-scan a printed sample with a few different phones before running a full print batch.

Do QR codes expire?

A static QR code, like the ones this tool generates, never expires; the data is encoded directly into the pattern and works for as long as the destination itself remains valid. Only paid dynamic QR services, which redirect through a URL you control, can expire if that subscription lapses.

Static vs dynamic QR codes — which do I need?

A static QR code is free, permanent, and best when the destination will never change, such as a WiFi network or a fixed product page. A dynamic QR code costs more (usually a subscription) but lets you redirect an already-printed code to a new URL later, useful for packaging you can't easily reprint.

Will a QR code with my logo still scan reliably?

Usually yes, if the logo is small (roughly 20% or less of the code's area) and you use a high error correction level, since QR codes are designed to remain readable even with part of the pattern obscured. Always test-scan the final printed version before mass production.
