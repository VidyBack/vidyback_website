Build a "Discount Code Generator" as a single, self-contained, embeddable 

web tool for an ecommerce marketing site (VidyBack — a Shopify app that 

auto-generates and schedules product videos).
 
FUNCTIONALITY

- Generation mode toggle: "Single Code" vs "Bulk Codes"

- Code Style — dropdown with common ecommerce patterns:

    1. Percentage-based: {PREFIX}{PERCENT} — e.g. "SAVE20", "WELCOME15"

    2. Seasonal/Campaign: {WORD}{YEAR} — e.g. "SUMMER2026", "BFCM2026"

    3. Influencer/Affiliate: {NAME}{NUMBER} — e.g. "SARAH10", "JOHN20" — 

       for tracking which creator/partner drove which sales

    4. Random alphanumeric: fully random string, adjustable length — for 

       one-time-use or giveaway codes where guessability is a security 

       concern

- Core inputs (fields shown/hidden based on selected style):

    1. Prefix/Brand text (optional, e.g. store initials or campaign name)

    2. Discount value (number — used to auto-populate percentage-style 

       codes)

    3. Code length (for random style): 6-12 characters, slider or number 

       input

    4. Character set (for random style): Letters only, Numbers only, 

       Letters + Numbers, with an "Exclude ambiguous characters" toggle 

       (removes 0/O, 1/I/l, since these get manually mistyped by customers 

       at checkout — on by default)

    5. Casing: UPPERCASE (default — most Shopify stores use this), 

       Title Case, lowercase

- For Bulk mode, add:

    6. Quantity to generate (1-500, capped to keep the tool fast and the 

       file size reasonable)

    7. Ensure uniqueness — dedupe against previously generated codes in 

       the same batch (use crypto.getRandomValues for actual randomness, 

       not Math.random, since collision-avoidance matters here)

- Live preview updating as options change: single mode shows the code 

  directly; bulk mode shows the first 10 codes in a scrollable list with 

  a running total count

- Bulk mode export: "Download CSV" formatted to match Shopify's bulk 

  discount code import format (a simple one-column CSV of codes, since 

  Shopify's own discount UI lets sellers paste/upload a code list when 

  creating a discount) — add a short inline note that the CSV lists codes 

  only, and the discount type/value/rules still need to be set inside 

  Shopify's discount screen

- "Copy" button for single codes, "Copy All" for the bulk list

- Handle edge cases: prevent code length below 4 or above 20, warn if 

  requested bulk quantity with a short length/limited character set risks 

  duplicates (e.g. "4-digit numeric codes for 500 requested — collisions 

  are likely, consider a longer code")
 
DESIGN

- Clean, modern, mobile-first, fully responsive down to 320px

- Generated code(s) shown in a large, monospace, easily-copyable format — 

  this is the visual focal point

- Brand palette: [insert VidyBack hex codes here — default to a modern 

  teal/indigo palette if none given]

- Bulk mode list styled as a clean scrollable table with a sticky 

  "Download CSV" button
 
TECH

- Single self-contained HTML file, inline CSS, vanilla JavaScript

- Use crypto.getRandomValues() for randomness (not Math.random()) to 

  avoid predictable/guessable codes, especially relevant for the 

  giveaway/one-time-use case

- CSV generation and file download handled natively via a Blob and a 

  temporary anchor element — no backend, no external dependencies

- Semantic HTML, labeled inputs, basic ARIA for accessibility
 
SEO / ON-PAGE CONTENT

- Title: "Free Discount Code Generator for Shopify & Ecommerce Stores"

- Meta description (<155 chars) targeting "discount code generator", 

  "promo code generator shopify", "bulk discount code generator"

- Below the tool, add ~250-400 words covering:

    - Why unique codes per channel/influencer matter for attribution 

      (which source actually drove the sale)

    - Security note: predictable codes (like "SAVE10") can be guessed and 

      abused at scale if a store doesn't cap usage per code — recommend 

      pairing generated codes with Shopify's usage limits

    - How to bulk-import generated codes into a Shopify discount

- Add FAQ schema (JSON-LD) for 3-4 questions like "How do I create 

  multiple discount codes at once in Shopify?" and "Should discount codes 

  be random or memorable?"

Build a "Refund/Return Policy Generator" as a single, self-contained, 

embeddable web tool for an ecommerce marketing site (VidyBack — a Shopify 

app that auto-generates and schedules product videos).
 
FUNCTIONALITY

- A form collecting the inputs needed to populate a standard ecommerce 

  refund/return policy template:

    1. Business/store name

    2. Contact email (for return requests)

    3. Return window — number input + unit dropdown (days), common presets 

       as quick-select buttons: 7, 14, 30, 60 days

    4. Do you accept returns at all? — Yes / No (No generates a clear 

       "All Sales Final" policy instead of a return policy — still a 

       legitimate legal need, don't force a return flow if they don't 

       offer one)

    5. Condition requirements — checkboxes: Unused/unworn, Original tags 

       attached, Original packaging included, Proof of purchase required

    6. Non-returnable categories — checkboxes with common exclusions: 

       Final sale/clearance items, Personalized/custom items, Perishable 

       goods, Intimate/hygiene items (underwear, swimwear, earrings, 

       cosmetics), Gift cards, Digital products

    7. Who pays return shipping? — dropdown: Customer pays, Store pays, 

       Store pays only for defective/wrong items, Free returns via 

       prepaid label

    8. Refund method — checkboxes: Original payment method, Store credit, 

       Exchange only (no refunds)

    9. Refund processing time — number input (business days) after the 

       return is received

    10. Do you charge a restocking fee? — Yes (enter %) / No

    11. Damaged/defective item process — short free-text field describing 

        how customers should report it (e.g. "email photos within 48 

        hours of delivery") — inserted verbatim into a dedicated clause

- Generate a complete, formatted policy by inserting answers into a 

  pre-written legal template using conditional logic (not an AI call):

    - Skip/adapt entire sections based on Yes/No answers (e.g. no 

      restocking fee clause at all if "No" is selected)

    - Auto-insert today's "Last Updated" date

- Output panel: rendered formatted policy + "Copy to Clipboard" + 

  "Download as .txt/.docx" buttons

- Live preview updates as fields are filled in, not just after final 

  submit — same two-column pattern as the Privacy Policy tool
 
DESIGN

  across your tool suite

  teal/indigo palette if none given]

TECH

- Template assembly and conditional logic run entirely client-side — 

  no backend, no AI/API call, no data transmitted or stored

- Semantic HTML, labeled form fields, basic ARIA for accessibility
